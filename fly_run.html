Welcome to the Fly Run Test!

Thank you for helping me test my first mobile game!

Fly Run is a simple Jump & Run game that I am currently preparing for its first release on Google Play. Your participation helps me make sure everything works correctly before the public release.

How to participate

To participate in the test, please follow these steps:

  1. Join the Google test group first:
    Join the Google Test Group
  2. Become a Tester:
    Become a Tester
  3. After joining the group, download and install Fly Run from Google Play.
    Download Fly Run
  4. Keep the game installed on your device for 14 days.
  5. During these 14 days, you only need to play the game occasionally. You do not need to play every day or for a specific amount of time.
  6. At the end of the test period, Google will provide a questionnaire where you can give feedback about the game.

What I need from you

The main goal of this test is to find bugs, technical problems and things that could be improved before the public release.

You do not need to actively search for bugs. Just play the game normally from time to time and let me know if you notice anything unusual.

Feedback is very welcome. You can send any feedback, suggestions or problems directly to:

wildnovagames@gmail.com
